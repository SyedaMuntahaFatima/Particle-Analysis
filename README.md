# Particle-Analysis
Python exercises and data analysis practice for Data research.
## About This Project
This repository contains my Python practice exercises as part of my Master's thesis preparation in particle physics.
## Exercise : Particle Energy Analysis
### Objectives
- Create artificial particle-energy values in GeV.
- Calculate the number, minimum and maximum of values.
- Select energies above a given threshold.
- Create a function for energy selection.
- Plot a histogram using Matplotlib.
- Study the effects of changing the threshold and histogram binning.
